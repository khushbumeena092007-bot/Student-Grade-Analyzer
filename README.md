
# Student Grade Analyzer

## 📌 About the Project

Student Grade Analyzer is a Python-based project that analyzes student examination data and generates useful performance reports.

The project uses Pandas to clean and process student data, calculate grades and percentages, rank students, identify students who may be at risk, and generate summary reports.

## 🎯 Features

* Clean and process student data
* Handle missing values
* Calculate student percentages and grades
* Rank students based on performance
* Generate Top 10 and Bottom 10 student reports
* Calculate subject-wise failure rates
* Identify at-risk students
* Generate class and gender summaries
* Create graphs for data visualization
* Export reports to an Excel file

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Streamlit
* OpenPyXL

## ⚙️ Installation

Clone the repository and install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Run the Streamlit application using:

```bash
streamlit run app.py
```

Then open the URL shown in the terminal.
